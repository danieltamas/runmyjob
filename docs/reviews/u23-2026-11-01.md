- P2 SQLite opened on every reload on the main actor: fixed for the repeated open (the service is created once); the first open is still on the main actor.
- P2 paths shown raw: fixed, `UntrustedText.clean` on target and item paths.
- P2 edit overwrote a changed file: fixed, every edit starts from the file as it is on disk.
- P2 a run's problem not shown: fixed, the result list shows it.
- P2 ledger open errors swallowed: fixed, the pane says the ledger cannot be opened.
