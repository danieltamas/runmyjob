# U15 box sensors, Codex review 2026-10-31

Reviewed: the final diff (probe steps, BoxSensors, SensorChips, card view). Findings and what was done:

- P1 `net` step: an interface name of 7 or more characters (tailscale0, docker0) has no leading space in /proc/net/dev, which shifted the fields. Fixed: the leading blanks are stripped and the line is split on `:` and blanks; virtual interfaces (lo, veth, docker, br-, virbr) are left out so container traffic is not counted twice. Checked on a synthetic file and on the real box.
- P2 `Int(seconds)` on a huge uptime, and Int overflow on memory and disk sizes from the box: sizes beyond a petabyte in MB and uptimes beyond 1000 years are not shown.
- P2 CPU above 100 percent from inconsistent counters: clamped.
- P2 rates across a reboot: an interval whose two probes have different boot ids is void.
- P2 fan animation while the panel is closed: the fan turns only while the panel is visible.
- P2 history bounded by count, not time: the chips use the last 30 minutes of probes.
- P2 a failed probe replaced the cached readings: a probe that never reached the box is not added to the history; the card's own readings keep their existing behaviour (the capacity lines vanish the same way), unchanged.
