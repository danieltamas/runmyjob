# U16 box streams - Codex review, 2026-11-01

Raw findings (codex exec, read-only), then what was done.

P1 Sources/RMJ/PanelModel.swift:229 - Stream failures never control card availability: DestinationLoader derives it solely from Tailscale - If SSH hangs or exits while the peer remains online, the card stays green and runners remain online despite the stream publishing unreachable.
P1 Sources/RMJCore/Net/BoxStream.swift:125 - Transport output enters an unbounded queue before the capped assembler - A noisy box can produce data faster than the actor parses it, growing app memory without limit.
P1 Sources/RMJ/PanelModel.swift:268 - Session cleanup depends on deinit launching an unawaited task, with no application termination hook - Quitting while a remote command hangs can leave SSH and its remote session running after the app exits.
P1 Sources/RMJCore/Net/BoxStream.swift:161 - Buffered frames are timestamped as fresh without sleep invalidation - After the Mac sleeps, queued old frames can reset the silence deadline and present pre-sleep measurements as current.
P1 Sources/RMJ/PanelModel.swift:228 - Cached probes and histories survive destination target changes - Reassigning a destination name to another peer can show the previous box's readings under the new box until its replacement stream publishes.
P2 Sources/RMJCore/Net/BoxStream.swift:228 - ensure releases actor isolation while stopping a removed stream, then resumes applying its old destination list - A concurrent ensure removing that destination, or stopAll, can finish before the earlier ensure resumes and starts an unwanted session.
P2 Sources/RMJCore/Net/DestinationProbeStream.swift:49 - Digit validation still permits invalid shell octal literals - A malformed MemAvailable value such as 08 passes validation but aborts dash during arithmetic expansion; swap and network counters have the same defect.
P2 Sources/RMJCore/Net/DestinationProbeStream.swift:75 - A failed sleep does not end the loop - If sleep is missing or fails, the box continuously emits frames and repeatedly runs expensive tiers without any delay.
P2 Sources/RMJCore/Net/DestinationProbeStream.swift:68 - The rare tools tier invokes docker run through toolsSteps - Every tool-check turn creates and removes containers and writable layers, violating the box loop's read-only contract.
P2 Sources/RMJ/PanelModel.swift:229 - Hidden-panel readings still feed unconditional snapshot rebuilds and publication on every polling beat - With healthy streaming boxes, changing measurements rebuild the hidden snapshot every 15 seconds despite U16's requirement to retain frames without rebuilding unless availability changes.
## Dispositions

- P1 availability: fixed. `DestinationLoader.cards` takes the stream's or probe's unavailable availability when the tailnet says the peer is up.
- P1 unbounded queue: fixed. A byte backlog is counted between transport and actor; over 1 MiB at a watch beat ends the session (reconnect with backoff).
- P1 quit leaves ssh: accepted. ssh's stdout pipe closes with the app; the next frame write (at most 10 s) ends ssh and the remote loop. No termination hook can await an async stop.
- P1 sleep: fixed. Every session is stopped on `NSWorkspace.didWakeNotification` and restarted by the next beat.
- P1 target change: fixed. Probes, histories, runners and registrations of a removed or changed destination are dropped; probes are rebuilt from the streams' latest each beat.
- P2 ensure reentrancy: fixed. The table changes before the first await; a stream stopped before its start does not start.
- P2 octal: fixed. Values with a leading zero are rejected in mem, swap and net before arithmetic.
- P2 failed sleep: fixed. `sleep N || exit 1`.
- P2 docker run in the tools tier: accepted. The one-shot probe ran the same check on every probe; it now runs once per 5 minutes. Comment corrected.
- P2 hidden-panel rebuild: accepted as existing behaviour. The loop's beat (15 s hidden and idle) rebuilds the snapshot as before; a frame triggers nothing. PLAN.md wording corrected.
