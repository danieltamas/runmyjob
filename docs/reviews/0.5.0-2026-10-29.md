# Review 0.5.0 (Codex, security persona, read-only) - 2026-10-29

P1 Sources/RMJCore/Ops/DestinationSetup.swift:164 - Setup passes unvalidated rule image names into shell text. If image listing fails after prerequisites succeed, line 92 still runs toolSteps because the failure is named "images". With requires=["jq"], image="rx-x; printf INJECTED; #" executes the injected command as the box's SSH user. Confirmed with a harmless shell stub.

P2 Sources/RMJCore/Run/DockerPlan.swift:32 - Forcing the SSH user's UID/GID breaks shipped images on boxes whose user is not UID 1000. The Rust image and its cache volumes remain owned by UID 1000; a UID 1001 job cannot write /target or Cargo caches. The container starts, so this becomes a failed build without local fallback.
Resolution: P1 fixed (tool steps only run for valid image names and never after a failed image listing); P2 documented in docs/ROUTING.md (non-1000 box users set hardening false or a profile user).
