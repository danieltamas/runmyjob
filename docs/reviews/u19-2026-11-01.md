# U19 review (Codex, read-only), 2026-11-01

Diff: `Sources/RMJCore/Run/*`, `Support/box/rx-run.sh`.

## Findings

- P1 `AgentSession.swift:45` - Persisted transcripts bypass credential redaction: a tool that reads `$HOME/.claude/.credentials.json`
  records its raw result in the bind-mounted session directory, so login tokens can stay on the box disk although stdout is redacted.
- P2 `AgentSession.swift:60` - The session key omits the tenant: reassigning a repo to another tenant on a shared destination
  would reuse the previous tenant's transcripts.

## Disposition

- P1: accepted, residual risk, documented in docs/AGENTS-ON-BOXES.md. The directory is mode 700 under the box user, pruned
  after 14 days, and the login is an access token with the lifetime check the run already enforces. Only a prompt-injected agent
  that deliberately prints its own login file reaches it. A scrub of the session files on the Mac side (it knows `secrets`) is the
  follow-up if the owner wants it closed.
- P2: not applicable as written. A destination serves one tenant (rules validation rejects a destination whose runner targets
  belong to another company) and the acceptance tests pin the key to the repo slug alone. Only `shared` tenants use any box, and
  their repos have different slugs.
