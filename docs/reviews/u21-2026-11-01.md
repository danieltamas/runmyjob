Diff: the cleaner (`Sources/RMJCore/Clean/`), schema step 3, `Retention`, `rmj clean`. Findings as returned, with what was done.

- P0 `Cleaner.swift` - only the last component is checked for a link; a linked ancestor could lead a configured path elsewhere. Not changed: the ancestors are the owner's own `clean.json`, a candidate is a real directory directly under its parent, and removal never follows a link inside it. A config that names a link to another tree is the owner's choice.
- P0 `Cleaner.swift` - the path is checked, then removed. Fixed for scratch: device and inode are taken at measurement and compared right before removal; a changed directory is left ("changed while cleaning").
- P0 `CleanWorktrees.swift` - state can change between the checks and `git worktree remove`. Not changed: the removal is never `--force`, so git itself refuses a worktree that became dirty; the window is the idle threshold (48 h by default) plus the in-use snapshot, and a commit made in that window is on the branch, which is kept.
- P0 `CleanSupport.swift` - non-empty `lsof` output accepted whatever the status. Fixed: only exit 0 or 1 (1 = some processes not visible); anything else counts every candidate as in use.
- P0 `CleanWorktrees.swift` - a failed `stat` of HEAD or index passed the recency check. Fixed: failure skips ("cannot read ... times"); only a missing index on a fresh worktree is allowed.
- P1 `Cleaner.swift` - the pending marker was cleared before the outcome line. Fixed: cleared after the append succeeds; a failed append leaves it.
- P1 `Cleaner.swift` - the first removal could run with an unwritable `clean.log`. Fixed: a `start` line is written before anything else; failure stops all removals.
- P1 `CleanSupport.swift` - concurrent cleaners shared one marker. Fixed: `clean.lock` (flock, non-blocking); a second run reports a problem and does nothing.
- P1 `CleanSupport.swift` - pruning the log raced appends. Fixed: pruning takes the same lock and skips when a run holds it.
- P1 `CleanSupport.swift` - the log followed a link. Fixed: opened with `O_NOFOLLOW`, must be a regular file owned by the user.
- P2 `Cleaner.swift` - a listing error became an empty candidate list. Fixed: an unlistable parent or `.worktrees` is a skipped item with the reason.
