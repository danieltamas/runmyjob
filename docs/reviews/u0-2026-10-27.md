## Declined

- ProcessRunner session escape and unbounded output accumulation: ProcessRunner is MacMax's file
  carried over unchanged in behavior (PLAN: copy, do not rewrite). A grandchild that starts its own
  session, and a cap on captured output, belong to U4's run engine, which streams a job to the box
  log and bounds what it keeps; recorded for U4.
- PatHandoff sweep racing a fresh offer for the same account, and symlink swaps inside the 0700
  `~/.rmj`: the attacker that can do this already runs as the user who owns the Keychain items and
  every file there, so no boundary is crossed. The window is microseconds and the sweep only runs
  at app launch, on offer and on take.
- Account names with `/` or `:` in PatHandoff: runner target names are validated tokens (U6); the
  acceptance tests require a plain-token account.
